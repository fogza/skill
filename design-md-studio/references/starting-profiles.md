# Starting profiles

Discover context first. Existing CSS/theme/components outrank starters even without DESIGN.md. With no visual evidence, interview gaps and confirm a brief covering audience/job, platform, languages/accessibility, constraints and binding assets. Profile selection is not final approval.

| Profile | Contents | Use when |
|---|---|---|
| Structure only | Relevant canonical sections, known facts and undecided fields; no invented palette/fonts | Exploring structure or missing decisions |
| Framework native | Installed scales and overrides, small semantic map, no duplicated default theme | A known framework foundation is acceptable |
| Neutral starter | Unconfirmed light/dark neutrals, system sans, compact type/spacing/radius scales | A blank project needs concrete values to react to |

Structure only: keep undecided values in prose and review them as prose entries, not placeholder color/number tokens. Framework native: inspect the installed version, do not guess defaults or install a framework; distinguish inherited from custom.

Neutral starter values are proposed samples, not a universal identity:

| Role | Light | Dark |
|---|---|---|
| background | #ffffff | #171717 |
| foreground | #171717 | #fafafa |
| primary | #171717 | #fafafa |
| primary-foreground | #fafafa | #171717 |
| muted | #f5f5f5 | #262626 |
| muted-foreground | #525252 | #d4d4d4 |

- Font: system-ui, sans-serif, subject to required scripts/languages; no automatic external font fetch.
- Body: 1rem/400/1.5; title: 1.5rem/600/1.3; label: 0.875rem/500/1.5. Add roles from actual needs.
- Spacing base: 0.25rem; examples: 0.5rem, 1rem, 1.5rem. Radius: 0.25rem, 0.5rem, 0.75rem. Inherit equivalent framework scales rather than competing aliases.
- No automatic brand hue, icon library, imagery, perpetual animation, shadow ladder or domain status roles.

Show swatches/text samples; mark starters as preset and verify edited intended pairs. Never treat preselection as the user's choice.
